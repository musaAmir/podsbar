# PodsBar 1.2.0

## A new popover

- Left, right, and case each get a tile with a capsule that fills like the menu bar icon, and a large percentage.
- A bud at 20% or lower turns red, with a notice to charge it soon.
- The header shows the device name, whether it's connected, and when levels were last updated.
- The menu bar display is a segmented control: Both buds, Lowest bud, or Icon only.
- Launch at login and automatic update checks are switches.
- Check for Updates and Quit look like menu items, with the current version shown.
- A clearer empty state when no AirPods are connected.

## Install

If you have PodsBar 1.1.0, choose **Check for Updates…** in the popover.

Otherwise, download PodsBar-1.2.0.zip, extract it, quit any running copy of PodsBar, and copy PodsBar.app to Applications.

## Validation and limitations

27 Swift tests and 11 release-script tests pass locally. The new popover was rendered and checked in light mode, dark mode, low battery, and with nothing connected. Intel runtime testing and a notarized end-to-end update installation remain to be completed.
