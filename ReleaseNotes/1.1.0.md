# PodsBar 1.1.0

## Improvements

- Lower idle memory use through an AppKit menu-bar host and an on-demand popover.
- Fewer duplicate Bluetooth scans, with polling paused during system sleep.
- Scan deadlines, cancellation, bounded output, and clearer errors when readings cannot be refreshed.
- Preferred-device selection, improved Bluetooth report parsing, and better handling of case-only records.
- Improved launch-at-login controls and accessibility labels.
- Sparkle update checks, a Check for Updates button, and a switch for daily automatic checks.
- A universal app for Apple silicon and Intel Macs running macOS 14 or later.

## Install

Download PodsBar-1.1.0.zip, extract it, quit any running copy of PodsBar, and copy PodsBar.app to Applications.

Existing versions without Sparkle require this one manual download. This version can check the signed GitHub update feed for future releases. Automatic checks are enabled by default; downloads and installation require user approval by default.

## Validation and limitations

27 Swift tests, 11 release-script tests, and Sparkle startup/signing/tamper tests pass locally. The bundle has been built for Apple silicon and Intel; Intel runtime testing and a notarized end-to-end update installation remain to be completed.
